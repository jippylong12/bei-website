# Repository Instructions

## Brand Compliance

- All future website work must follow `DESIGN.md` and `BEI_Brand_Guidelines.pdf`.
- Treat `BEI_Brand_Guidelines.pdf` as the canonical brand source. If `DESIGN.md` conflicts with the PDF, follow the PDF and update `DESIGN.md`.
- Preserve the BEI brand tone: scholarly, credible, timeless, principled, Bitcoin-native, institutional, and measured.
- Do not introduce non-brand palettes, hype-driven crypto visuals, generic crypto language, or public exploratory theme systems unless Marcus explicitly approves a brand-guide update.
- Use approved logo assets from `public/brand/` and follow the clear-space, minimum-size, and incorrect-usage rules in `DESIGN.md`.

## Tool Preferences

- Do not use the Browser plugin, in-app browser, browser-use tooling, or browser automation unless Marcus explicitly asks for Browser in the current request.
- For UI work, prefer code inspection, automated tests, build checks, and user-provided screenshots. Ask before starting browser-based visual review.
