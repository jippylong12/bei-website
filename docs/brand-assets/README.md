# BEI Brand Assets

The official source guideline is `BEI_Brand_Guidelines.pdf` at the repository root. This directory stores print/source PDFs and maps the original asset bundle into the organized repository layout.

## Asset Locations

| Brand role | Web assets | Print/source assets | Original folder |
| --- | --- | --- | --- |
| Primary horizontal logo | `public/brand/primary-horizontal-logo/` | `docs/brand-assets/primary-horizontal-logo/` | `tmp/01_PRIMARY_HORZIONTAL_LOGO/` |
| Wordmark | `public/brand/wordmark/` | `docs/brand-assets/wordmark/` | `tmp/02_WORDMARK/` |
| Monogram / secondary mark | `public/brand/monogram-mark/` | `docs/brand-assets/monogram-mark/` | `tmp/03_MARK/` |

## Notes

- Use SVG files for website implementation whenever practical.
- Use PNG files for transparent-background raster contexts.
- Use PDF files for print, vendor handoff, and formal document work.
- The current bundle includes primary horizontal logo, wordmark, and monogram/secondary mark files. If a standalone column icon asset is supplied later, add it under `public/brand/icon/` and document it here.
- Do not recolor, distort, add effects to, or recreate these assets.
